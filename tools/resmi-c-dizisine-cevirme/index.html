Resmi C Dizisine (Hex Koda) Çevirme

Bir resim bırakın, ekran boyutunu seçin ve derlenmeye hazır C dizisini kopyalayın. Dithering sayesinde fotoğraflar 1-bit OLED ekranda bile okunur kalır.

Nasıl kullanılır?

  1. PNG, JPG, GIF, BMP veya WebP resmi yükleyin, sürükleyin ya da Ctrl+V ile yapıştırın.
  2. Genişlik ve yüksekliği ekranınıza göre ayarlayın (0.96" SSD1306 için 128 × 64).
  3. Logo ve yazı için Threshold, fotoğraf için Atkinson veya Floyd–Steinberg seçin.
  4. Kütüphanenize uygun çıktıyı seçin (Adafruit GFX, U8g2 XBM, MicroPython) ve .h dosyasını kopyalayın.

// Paste the array generated above:
static const uint8_t PROGMEM bitmap[] = { 0xff, 0x80, /* ... */ };

void setup() {
  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  display.clearDisplay();
  display.drawBitmap(0, 0, bitmap, 128, 64, SSD1306_WHITE);
  display.display();
}

void loop() {}

Sıkça sorulan sorular

C dizisi kaç bayt olur?

1-bit çıktı için tavan(genişlik / 8) × yükseklik bayttır; 128 × 64 için 1024 bayt.

Resim ekranda ters (negatif) görünüyor.

"Invert" kutusunu işaretleyin veya drawBitmap() içindeki renk parametresini değiştirin.

MicroPython framebuf Image Converter

Get a bytearray and a framebuf.FrameBuffer you can blit() straight onto an SSD1306 from MicroPython on ESP32 or Raspberry Pi Pico.

Using the output

from machine import Pin, I2C
import framebuf, ssd1306

i2c = I2C(0, scl=Pin(22), sda=Pin(21))   # Pico: I2C(0, scl=Pin(1), sda=Pin(0))
oled = ssd1306.SSD1306_I2C(128, 64, i2c)

bitmap = bytearray([0xff, 0x80, ...])    # from the converter
fb = framebuf.FrameBuffer(bitmap, 128, 64, framebuf.MONO_HLSB)
oled.blit(fb, 0, 0)
oled.show()

MONO_HLSB, MONO_HMSB and MONO_VLSB

The converter emits MONO_HLSB (horizontal, MSB = leftmost pixel), which matches the Adafruit layout. MONO_VLSB corresponds to the vertical pages layout used internally by the SSD1306.

Frequently asked questions

Does it work with CircuitPython?

CircuitPython uses displayio and bitmap files, but the raw bytes from this tool can be loaded into a displayio.Bitmap with a small loop.

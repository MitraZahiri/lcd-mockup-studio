C Array to Image Viewer

Found a static const unsigned char PROGMEM logo[] in someone's firmware and want to see what it draws? Paste the whole array here.

Reverse engineering bitmaps in firmware source

Arduino and embedded projects store splash screens, icons and fonts as C arrays in header files. Reading 0x3c, 0x42, 0x81... by eye is impossible, so this viewer renders them for you. It understands:

  • uint8_t, unsigned char, char and byte arrays, with or without PROGMEM / U8X8_PROGMEM
  • Array size declarations like logo[1024] (the 1024 is not mistaken for data)
  • // line and /* block */ comments, and #define LOGO_WIDTH 128 dimension macros
  • Multiple formats: Adafruit_GFX, XBM, U8g2 vertical pages, RGB565 and 8-bit grayscale

Example input

#define logo_width 16
#define logo_height 16
static const unsigned char logo_bits[] PROGMEM = {
  0xe0, 0x07, 0x18, 0x18, 0x04, 0x20, 0x02, 0x40,
  0x32, 0x4c, 0x31, 0x8c, 0x01, 0x80, 0x01, 0x80,
  0x01, 0x80, 0x09, 0x90, 0x12, 0x48, 0xe2, 0x47,
  0x04, 0x20, 0x18, 0x18, 0xe0, 0x07, 0x00, 0x00 };

This is a 16 × 16 XBM smiley. Paste it into the tool above, pick XBM and it appears immediately.

Frequently asked questions

How do I find the width and height of a C bitmap array?

Look for #define …_WIDTH / …_HEIGHT macros or the drawBitmap() call that uses the array. If there are none, divide the byte count: for 1-bit horizontal data, bytes = ceil(width/8) × height. The auto-detect button tries common display sizes for you.

Can I edit the image and get a new C array back?

Yes. Click "Open in full editor" to load the array into LCD Mockup Studio, draw or erase pixels, and the C code updates live in the same format.

Does it work with STM32, ESP-IDF or plain C projects?

Yes. The parser only looks for the byte values, so the platform does not matter.

Image to C Array Converter

Drop an image, choose your display size and copy a ready-to-compile C array. Dithering keeps photos and gradients readable on 1-bit OLED and LCD screens.

How to convert an image to a C array

  1. Upload, drag-and-drop or paste (Ctrl+V) a PNG, JPG, GIF, BMP or WebP image.
  2. Set the target width and height – for a 0.96" SSD1306 that is 128 × 64.
  3. Pick a dithering method. Use Threshold for logos and text, Atkinson or Floyd–Steinberg for photos.
  4. Choose the output that matches your library (Adafruit GFX, U8g2 XBM, vertical pages or MicroPython) and copy or download the .h file.

Using the array with U8g2

Select the XBM output, because drawXBMP() expects LSB-first horizontal bytes:

#include 

U8G2_SSD1306_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0, U8X8_PIN_NONE);

// XBM output (LSB-first, horizontal):
static const unsigned char bitmap[] U8X8_PROGMEM = { 0xff, 0x01, /* ... */ };

void setup() {
  u8g2.begin();
  u8g2.clearBuffer();
  u8g2.drawXBMP(0, 0, 128, 64, bitmap);
  u8g2.sendBuffer();
}

void loop() {}

Choosing a dithering algorithm

MethodBest for
ThresholdLogos, icons, text, line art – crisp edges, no noise
AtkinsonPortraits and photos on small OLEDs – high contrast, classic Mac look
Floyd–SteinbergSmooth gradients and detailed photos
Bayer 4×4 / 8×8Retro ordered pattern, stable when animating frames

Frequently asked questions

How big will my C array be?

For 1-bit output it is ceil(width / 8) × height bytes, e.g. 1024 bytes for 128 × 64. That fits easily in the flash of an Arduino Uno (32 KB) when stored with PROGMEM.

Why is my image inverted on the display?

Some libraries draw the 1-bits in the background color. Tick "Invert" or swap the color argument in drawBitmap().

Does the image get uploaded anywhere?

No. Conversion runs locally in your browser with the Canvas API.

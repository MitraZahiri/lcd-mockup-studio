Make a splash screen or icon for your 0.96" or 0.91" SSD1306 OLED. Upload an image, preview it at real pixel size and paste the code into your sketch.

SSD1306 memory layout

The SSD1306 controller stores its GDDRAM in 8 horizontal pages. Each byte is a vertical strip of 8 pixels with the least significant bit at the top. Libraries hide this:

  • Adafruit_SSD1306 takes horizontal MSB-first bitmaps in drawBitmap() and converts them itself – choose the Adafruit GFX output.
  • U8g2 drawXBMP() takes XBM (horizontal LSB-first) – choose XBM.
  • Writing straight to the controller over I²C (no library) needs the vertical pages layout.

Arduino example (Adafruit_SSD1306)

#include 
#include 

Adafruit_SSD1306 display(128, 64, &Wire, -1);

// Paste the array generated above:
static const uint8_t PROGMEM bitmap[] = { 0xff, 0x80, /* ... */ };

void setup() {
  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  display.clearDisplay();
  display.drawBitmap(0, 0, bitmap, 128, 64, SSD1306_WHITE);
  display.display();
}

void loop() {}

Arduino example (U8g2)

#include 

U8G2_SSD1306_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0, U8X8_PIN_NONE);

// XBM output (LSB-first, horizontal):
static const unsigned char bitmap[] U8X8_PROGMEM = { 0xff, 0x01, /* ... */ };

void setup() {
  u8g2.begin();
  u8g2.clearBuffer();
  u8g2.drawXBMP(0, 0, 128, 64, bitmap);
  u8g2.sendBuffer();
}

void loop() {}

Frequently asked questions

What size should an SSD1306 bitmap be?

128 × 64 pixels (1024 bytes) for the 0.96" module and 128 × 32 (512 bytes) for the 0.91" module. Smaller icons can be drawn anywhere on screen.

My SSD1306 image is shifted by 2 pixels.

Your module probably has an SH1106 controller (132-column RAM). Use an SH1106 driver or the U8g2 SH1106 constructor.

Does this work with ESP32 and ESP8266?

Yes. The generated header uses PROGMEM guards that compile on AVR, ESP8266, ESP32 and ARM.

Image to Byte Array Converter

Turn any picture into a compact array of hex bytes. Each byte stores 8 pixels, ready for microcontrollers, e-paper, LED matrices and thermal printers.

What the output looks like

// 16 × 8 px, 16 bytes, horizontal MSB-first
static const uint8_t PROGMEM bitmap[] = {
  0x3c, 0x3c, 0x42, 0x42, 0x81, 0x81, 0xa5, 0xa5,
  0x81, 0x81, 0x99, 0x99, 0x42, 0x42, 0x3c, 0x3c
};

Each 1 bit is a lit pixel and each 0 bit is dark. Choose a different output format above if your driver expects vertical bytes or LSB-first order.

Typical uses

  • Splash screens and icons for SSD1306, SH1106 and ST7920 displays
  • Images for Waveshare / GxEPD2 e-paper panels
  • Sprites for MAX7219 LED matrices and HUB75 panels
  • Logos for ESC/POS thermal receipt printers

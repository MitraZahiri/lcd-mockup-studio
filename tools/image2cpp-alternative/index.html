A Modern image2cpp & LCD Assistant Alternative

image2cpp and LCD Assistant are classics. LCD Mockup Studio does the same job, works in both directions (image → code and code → image) and lets you edit the result.

Moving over from image2cpp

Settings map directly: "Horizontal – 1 bit per pixel" is the Adafruit GFX output, "Vertical – 1 bit per pixel" is vertical pages, and "Arduino code" is the default header with PROGMEM. Try it with the converter at the top of this page.

Frequently asked questions

Is LCD Mockup Studio free?

Yes, it is free and MIT-licensed. The source is on GitHub.

Will my existing image2cpp arrays work?

Yes. Paste them into the hex to image tool to view or edit them; the byte formats are identical.

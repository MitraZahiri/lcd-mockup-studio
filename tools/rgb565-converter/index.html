RGB565 Hex to Image Viewer

Paste RGB565 color data from a TFT_eSPI, Adafruit or LVGL project and see the image. Switch endianness if the colors look wrong.

How RGB565 works

Each pixel is 16 bits: 5 bits red, 6 bits green, 5 bits blue. 0xF800 is red, 0x07E0 green, 0x001F blue and 0xFFFF white. A 240 × 320 ILI9341 frame is 153,600 bytes.

Big-endian vs little-endian

If reds look blue-green or the picture is noisy, the two bytes of each pixel are swapped. Toggle between RGB565 BE and RGB565 LE. TFT_eSPI pushImage() data is usually stored little-endian in memory; SPI transfers are big-endian.

Frequently asked questions

Can I paste uint16_t arrays like 0xF800?

Paste them as byte pairs (F8 00) or split 0xF800 into 0xF8, 0x00. A uint16_t parser is on the roadmap.

Can I convert an image to RGB565 here?

This page only decodes RGB565 data back into an image. For converting images, use the 1-bit image to C array converter.

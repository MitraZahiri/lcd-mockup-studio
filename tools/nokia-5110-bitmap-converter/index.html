Nokia 5110 (PCD8544) Bitmap Converter

The Nokia 5110 LCD is 84 × 48 pixels (504 bytes). Upload an image, tune the dithering and copy the array for your Arduino sketch.

PCD8544 memory layout

Like the SSD1306, the PCD8544 controller uses 6 vertical banks of 8 pixels. With the Adafruit_PCD8544 library use the Adafruit GFX output and display.drawBitmap(0, 0, bitmap, 84, 48, BLACK). When writing directly to the controller, pick the vertical pages output.

Tips for an 84 × 48 screen

  • Crop the image to a 7:4 aspect ratio first.
  • Use Threshold for text and logos; at this resolution dithering noise is very visible.
  • The display is dark-on-light: tick Invert if your logo appears as a negative.

Frequently asked questions

How many bytes is a Nokia 5110 bitmap?

84 × 48 / 8 = 504 bytes for a full screen.

Does this work for the Nokia 3310 display?

Yes, the Nokia 3310 and 5110 use the same 84 × 48 PCD8544 controller.

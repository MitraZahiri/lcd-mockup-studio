Hex to Image Converter

Paste raw hex bytes, a 0x.. list or a full C array below and the bitmap is decoded instantly in your browser. Nothing is uploaded.

How to convert hex to an image

  1. Paste your hex data into the box. All common notations work: 0xFF, 0x81, FF 81 7E, \xff\x81, continuous strings like FF817E, and complete C/C++ headers with comments.
  2. The tool counts the bytes and guesses the resolution. A 1024-byte buffer becomes 128 × 64, 504 bytes becomes 84 × 48, and so on. #define ..._width / _height lines are read automatically.
  3. If the picture looks scrambled, switch the byte format. Horizontal (Adafruit), XBM (LSB-first) and vertical page (SSD1306) layouts produce very different images from the same bytes.
  4. Click Download PNG to save a 1:1 pixel-perfect image, or Open in full editor to edit pixels and export new C code.

Why does my decoded image look wrong?

Hex bytes carry no width, height or bit order, so the same data can be read many ways. The three usual symptoms:

  • Diagonal stripes or a skewed image – the width is wrong. Try the auto-detect button or common widths such as 128, 84, 64 or 32.
  • Image is chopped into 8-pixel vertical blocks – the data uses horizontal rows but you selected vertical pages, or the other way round.
  • Each group of 8 pixels is mirrored – the bit order is reversed. Switch between Adafruit (MSB-first) and XBM (LSB-first).

Frequently asked questions

Is this hex to image converter free?

Yes. It is free, open source (MIT) and runs entirely in your browser. Your data is never uploaded to a server.

Can I convert hex to PNG or JPG?

You can download the decoded bitmap as a lossless PNG at its exact pixel size. PNG is the right format for 1-bit bitmaps because JPG compression would blur the pixels.

Which hex formats are supported?

0x-prefixed lists, space or comma separated byte pairs, \x escapes, continuous hex strings, Intel-style address prefixes, and complete C arrays with PROGMEM, comments and #define dimensions.

Can I decode color images?

Yes. Choose RGB565 (big- or little-endian) for 16-bit TFT data or Grayscale for one byte per pixel.

U8g2 XBM Bitmap Converter

U8g2 draws images in XBM format. This converter outputs exactly that – LSB-first horizontal bytes – ready for drawXBMP().

drawXBM vs drawXBMP

drawXBM() reads the bitmap from RAM; drawXBMP() reads it from flash (PROGMEM). On AVR boards always use drawXBMP() with a U8X8_PROGMEM array to save RAM.

#include 

U8G2_SSD1306_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0, U8X8_PIN_NONE);

// XBM output (LSB-first, horizontal):
static const unsigned char bitmap[] U8X8_PROGMEM = { 0xff, 0x01, /* ... */ };

void setup() {
  u8g2.begin();
  u8g2.clearBuffer();
  u8g2.drawXBMP(0, 0, 128, 64, bitmap);
  u8g2.sendBuffer();
}

void loop() {}

XBM vs Adafruit format

Both are horizontal, but XBM puts the leftmost pixel in the lowest bit, while Adafruit_GFX uses the highest. Feeding an Adafruit array into drawXBMP() mirrors every 8-pixel group. If your image looks like that, regenerate it here with the XBM output.

Frequently asked questions

Can I open .xbm files from GIMP?

Yes. XBM files are plain C. Paste the content into the hex to image tool to view or edit them.

Which U8g2 constructor should I use?

Use the full-buffer (_F_) constructor for your controller, e.g. U8G2_SSD1306_128X64_NONAME_F_HW_I2C, so drawXBMP() and sendBuffer() work as shown.

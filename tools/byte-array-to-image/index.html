Byte Array to Image

Paste a byte array from your code, a serial log or a memory dump. The tool turns it into pixels so you can see what the buffer holds.

Where byte arrays come from

  • Display frame buffers dumped over UART with Serial.print(buf[i], HEX)
  • Firmware binaries viewed in a hex editor, where bitmaps sit between code
  • Python / JavaScript bytearray or Uint8Array literals
  • I²C / SPI captures from a logic analyzer sending pixel data to a display controller

Whitespace-separated pairs (00 FF 18) and continuous strings (00FF18) are both accepted, so you can paste straight from a hex editor.

Bytes per pixel

1-bit formats pack 8 pixels into each byte, grayscale uses 1 byte per pixel and RGB565 uses 2 bytes per pixel. If you know the resolution, the byte count tells you the format: a 128 × 64 screen needs 1024 bytes in 1-bit, 8192 in grayscale and 16384 in RGB565.

Frequently asked questions

Can I convert a Python bytearray to an image?

Yes. Paste bytearray([0x00, 0xff, …]) or b"\x00\xff…" and the bytes are extracted automatically.

What if my byte array is decimal, not hex?

The tool expects hex. Convert decimals first (255 → 0xFF) or paste the hex output of your serial monitor.
